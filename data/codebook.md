# Codebook — sample data (fictional)

Codes used in `sample_coding.csv`. All excerpts are invented for
demonstration; no real participants, quotes, or personal data.

| Code | Meaning | Example cue |
|---|---|---|
| `genai_helpful` | GenAI helped the student learn, plan, or work faster | "drafted our timeline in seconds" |
| `genai_concern` | Worry about GenAI: accuracy, originality, over-reliance, integrity | "sounded confident but cited a formula that does not exist" |
| `equity` | Fairness, access, or who benefits / is left out | "only covered wealthy neighbourhoods" |
| `engagement` | Motivation, focus, enjoyment, participation | "stayed after class to keep playing" |
| `confusion` | Not understanding content, instructions, or the task | "could not tell when to use the chain rule" |

## Coding rules used for the sample

1. One code per excerpt — the dominant theme.
2. If an excerpt is both confused *and* engaged (e.g. E24), code the
   dominant theme; note the ambiguity in the disagreement list.
   This is exactly where `confusion` vs `engagement` disagreements
   cluster in the sample, and why that pair is worth a codebook
   clarification before a second coding round.
3. `genai_concern` is about the tool; `confusion` is about not
   understanding the material or instructions.
